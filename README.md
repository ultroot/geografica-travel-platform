# Geografica Travel Platform

Travel aggregation and enquiry platform for flights, visas, holiday packages, Umrah, forex, and travel services.

## Tech Stack

- Frontend: Next.js
- Backend: FastAPI
- Database: PostgreSQL
- Reverse Proxy: Nginx
- Containerization: Docker
- CI/CD: GitHub Actions
- Cloud: AWS

## Features

- Flight search
- Travel package listings
- WhatsApp enquiry integration
- Provider comparison
- SEO-friendly pages
- DevOps-focused architecture
